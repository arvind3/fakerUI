## Coverage Disclosure Copy

Coverage includes all built-in providers for the pinned Faker version and any plugin packs enabled in this repository. Unbundled third-party or custom providers are out of scope.

## Safety Copy

Generation runs in-browser with a whitelist of allowed Faker methods. No backend API is required for data generation.

## Product Maturity Note

Synthora is production-capable for engineering workflows, with active investment in UI/UX polish for broader non-technical adoption.
